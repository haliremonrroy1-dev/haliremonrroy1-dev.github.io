Política de privacidad de Anime Key Publicador

Última actualización: 22 de noviembre de 2026

Qué es

Anime Key Publicador es una aplicación privada que usa únicamente el administrador de Anime Key para publicar sus propios videos en su propio canal de YouTube. No tiene usuarios externos.

Qué datos usa

Con permiso del dueño de la cuenta, la aplicación usa los Servicios de API de YouTube para:

  • Subir videos al canal de YouTube del dueño (permiso youtube.upload).
  • Leer el nombre y el número de suscriptores de ese mismo canal para comprobar la conexión (permiso youtube.readonly).

No accede a datos de otros usuarios, comentarios, mensajes, contactos ni información de pago.

Dónde se guardan

El permiso de acceso (token) se guarda solo en la computadora del dueño. No se envía a ningún servidor propio ni a terceros.

Con quién se comparten

Con nadie. Los datos no se venden, no se comparten y no se usan para publicidad.

Servicios de terceros

Esta aplicación usa los Servicios de API de YouTube. Al usarla también aplican los Términos de Servicio de YouTube y la Política de Privacidad de Google.

Cómo quitar el acceso

El acceso se puede revocar en cualquier momento desde la configuración de seguridad de la cuenta de Google. Al revocarlo, la aplicación deja de poder subir videos y el token guardado deja de servir.

Contacto

Para cualquier consulta, escríbenos por mensaje a la página de Facebook Anime Key.
